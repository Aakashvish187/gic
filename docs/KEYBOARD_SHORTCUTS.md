# GIC Keybindings & Shortcuts Cheat Sheet

GIC uses intuitive modal editing keybindings.

## Modal Navigation

- **Normal Mode**: Navigate, search, undo, redo, and execute commands.
- **Insert Mode**: Type and edit text directly.
- **Search Mode**: Enter query to find and jump to matching text.

## Shortcuts List

| Mode | Shortcut | Action |
|---|---|---|
| All | `Ctrl+F` | Open search mode & query input |
| Search | `Enter` | Jump to next search match |
| Search | `Esc` | Close search & return to Normal mode |
| Normal | `i` | Switch to Insert mode |
| Normal | `Esc` | Return to Normal mode |
| Normal | `Ctrl+Z` | Undo previous edit |
| Normal | `Ctrl+Y` | Redo previous edit |
